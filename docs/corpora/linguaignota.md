# Lingua Ignota — el nomenclátor construido de verdad (Hildegard, ~1150)

**Fuente**: hildegardiana.es — glosario del Riesenkodex (Riesenkodex R,
fs. 461v-464v), 1.011 entradas. `data/raw/linguaignota.txt`,
`--format plaintext`.

**Por qué importa**: es el único vocabulario artificial documentado de
época medieval — la prueba de ácido para la lectura "Voynich = lingua
ignota / nomenclátor construido".

## Medido

- 999 tipos, ~100% hapax (es un glosario — lista, no texto)
- **fam ed1 = 10%** — pocas variantes a 1 edición
- **sufijos categóricos**: -iz 20%, -nz 14%, -ia 13%, -uz/-ol/-in/-az —
  la clase semántica se marca por terminación (cuasi-morfología)
- fonotáctica latina: vowel 0,41, cv_alt 0,70 — palabras pronunciables

## Lectura

El constructor real de vocabulario artificial **categoriza por
sufijos**; el Voynich genera **variantes densas a 1 edición** (75% fam)
sin morfología categórica. Firman distinto: si el Voynich es una lengua
construida, su mecanismo es combinatorio-variante, no nominalizador.
La clase "inventario" tiene ahora dos miembros y se ven las diferencias.
