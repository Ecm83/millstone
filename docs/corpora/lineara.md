# Lineal A (Creta minoica) — contabilidad palacial

**Fuente**: `Navarre-AI/linear-a` corpus.json (GORILA + SigLA collated).
**Adaptador**: `ingest/lineara.py` · **Niveles**: `symbol → word → doc → corpus`

Signos como codepoints Unicode: `U+106xx` fonéticos, `U+107xx`
ideogramas/logogramas (commodities), `U+101xx` números egeos.

## Hechos medidos

- 1.637 docs con texto · 3.767 palabras · 1.916 tipos
- Inventario de soportes: **913 nódulos + 489 tablillas + 194 roundels**
  ≈ 80% archivo administrativo
- **40% de tokens contienen números**; 42% de "palabras" son 1 solo signo
- hapax=89,7% — cada entrada es casi única (nombres, no léxico)
- Solo 24 secuencias multi-signo reaparecen en >1 doc — funcionarios
  mencionados en varios archivos
- `U+1076B` abre 1.284 palabras — ideograma de producto dominante

## Firma

**Contabilidad palacial**: listas `nombre + commodity + cifra`, no prosa.
El hapax extremo y los tokens numéricos son la firma de un archivo
administrativo — la misma clase de texto que Lineal B (descifrado porque
era griego contando ganado). La lectura "textos sagrados" no se sostiene:
la forma es la de la burocracia de almacén.
