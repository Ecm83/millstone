# data/

- `maps/` — candidatos de descifrado para `--map` / `testbed`
  (formato documentado en `toy-latin.map`; `bax2014.map` = Bax 2014
  Apéndice 1 completo; `drop-*.map` = controles de exclusión)
- `raw/` — corpus de terceros, **gitignored**: no van en el repo.
  Fuentes + comandos de descarga en `../docs/data.md`;
  `../scripts/fetch_data.ps1` baja los que tienen URL verificada.

Los corpus son de sus autores (IVTFF, CDLI, GORILA, Barthel, ICIT,
su.se, Wikisource, NCBI) — millstone no los redistribuye.
